# Salon Booking Platform

## Project Goal

A web and mobile platform for customers to discover salons,
select services and stylists, check available time slots,
and book appointments.

## Main Roles

- Customer
- Salon Owner / Manager
- Staff / Stylist
- Admin

## Main Booking Flow

Login → Discover Salon → Select Service → Select Stylist
→ Select Date/Time → Book → Manage Booking
